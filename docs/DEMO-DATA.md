# بيانات ماركت للتجربة فقط

```powershell
npm run demo:create
npm run test:demo
```

ينشئ المولد قاعدة جديدة في `work/demo-market-large-0.5.2/company.sqlite` ويرفض استبدال قاعدة موجودة. لإنشاء نسخة تجربة أخرى:

```powershell
node tools/create-demo.mjs work/my-demo
node tests/demo.smoke.mjs work/my-demo
```

240 صنفاً، 12 مورداً، 3 مخازن، 36 فاتورة شراء مرحلة، 408,000 وحدة مخزنية وقيمة تكلفة 987,400,000 دينار. الشراء نقدي وآجل ومختلط بحسب المورد، مع قيد رأس مال تجريبي يغطي التوريد وقيود المخزون/الموردين/الصندوق. أسعار البيع أعلى من الكلفة؛ الأرقام افتراضية للفحص وليست أسعار سوق أو أرصدة حقيقية.

الفئات: غذائيات، زيوت ومعلبات، أجبان وألبان، مياه وعصائر ومشروبات غازية تشمل بيبسي وسفن أب، حلويات، منظفات، لحوم ودواجن مجمدة، سكائر ولوازمها، جبس وسناكات، بهارات وشاي وقهوة، مخللات وصلصات، مخبوزات وعناية منزلية. لكل مادة صورتها التوضيحية المحلية وباركود EAN13 تجريبي يبدأ بـ200، واسم وسعر شراء وبيع وكمية ومورد. الصور رسوم عبوات توضيحية وليست صور منتجات تجارية حقيقية.

المجلد يحتوي CSV بالباركودات والأسعار، `catalog.json`، الصور، ملف HTML مستقل لطباعة جميع الباركودات، ونتيجة المطابقة `verification.json`. `test:demo` يفحص ظهور الصور واختيار المادة بالماوس واللمس ويصدر `barcodes-print.pdf`. الحسابات التجريبية فقط: admin / admin123.

لتشغيل بيانات تجربتك من مصدر المشروع في PowerShell:

```powershell
$env:ALMAHASIB_DB=(Resolve-Path .\work\demo-market-0.5.2\company.sqlite).Path
npm start
```

لا تستعد قاعدة التجربة فوق قاعدة شركة فعلية. أزل المتغير أو افتح نافذة PowerShell جديدة للعودة للمسار الافتراضي. بيانات العميل لا تُضاف تلقائياً: ملف قاعدة التجربة والصور والباركودات داخل `work/` فقط، وهو مستبعد من Git ومن قائمة ملفات مثبّت العميل. لا يعمل المولد أثناء بدء الخادم أو Electron؛ يلزم تشغيله يدوياً. الأدوات والاختبارات غير مشمولة في مثبّت العميل.

# مراجعة المخازن المحلية

الفرع: `development/functional-desktop`، مبني على `4b86fd98fb74087fb73d026c203b78623cc3ad43`.

المسار السابق `/workspace/scratch/23d8a511b284/AlMahasibPro-Desktop-Offline` لم يكن متاحاً في جلسة Windows. لم تُستعد منه تعديلات غير مرفوعة؛ نُفذت هذه التغييرات انطلاقاً من الفرع المنشور.

## المنفذ

- أرصدة مطوية، بحث بالاسم والرمز والباركود البديل والتصنيف واللون والقياس، فتح تفاصيل المخازن وحركة المادة وطباعة الأرصدة والحركة.
- مستندات إدخال وإخراج ومرتجعات وتجميع وفك: حفظ أولي، إعادة فتح وتعديل، اعتماد ذري مع فحص الإصدار ومنع إعادة الاعتماد، وطباعة الحالة. إعادة محاولة الطلب نفسه تستخدم مفتاح عملية لمنع التكرار.
- سجل وجبات فعلي مع صلاحية؛ الصرف يبدأ بالأقرب انتهاءً. جميع مسارات حركة المخزون المحلية، ومنها المبيعات والتسويات والتحويل، تمنع صرف المنتهي. التحويل يحتفظ بالوجبة والصلاحية. المرتجع من فاتورة بيع أو مستند إخراج محلي يحتفظ بوجباته الأصلية؛ مرتجع المستند المحلي لا يتجاوز كميته المتبقية.
- الباركودات البديلة ووحدات الحبة والكرتون ترتبط بصنف واحد وعامل تحويل؛ لا تنشئ أرصدة مستقلة. مسح الرمز مراراً يدمج الكمية في السطر نفسه مع إشعار نصي وبقاء تركيز الإدخال.
- التصنيف واللون والقياس والسعر الحالي قابل للتعديل.
- سيت بمكونات وكميات مختلفة: التجميع يصرف المكونات ويضيف السيت، والفك يعكس ذلك مع حفظ إجمالي القيمة. يحمل السيت أقرب صلاحية لمكوناته. تُمنع المكونات الدائرية والمتداخلة وتغيير تركيبة سيت له رصيد.
- قوالب ملصقات محلية: العرض والارتفاع وحجم الخط وإظهار الاسم والسعر وعدد النسخ، مع Code 128 يعمل دون اتصال. تجلب معاينة الملصق السعر الحالي، مضروباً بعامل الوحدة.
- بقيت أدوات التحويل والجرد والحجوزات والاستيراد متاحة داخل قسم مطوي.

الأرصدة القديمة غير المسجلة بوجبة وصلاحية تُحفظ كوجبة غير محددة، دون اختلاق تاريخ. مرجع المرتجع `STK-<id>` يربطه بمستند إخراج محلي؛ المراجع الخارجية تسجل الوجبة والصلاحية المدخلتين. الكميات أعداد صحيحة بوحدة الحبة وفق نموذج المخزون الحالي.

## التحقق

- الاختبارات السابقة الأربعة عشر واختبارات المخازن الأربعة نجحت محلياً على Windows / Node 24.
- فحص جميع صفحات الواجهة والعمليات السابقة نجح، وكذلك فحص المخازن المخصص: البحث والطي والفتح، المسح المتكرر، الأولي والاعتماد، طباعة الحركة، ورسم باركود الكرتون بالسعر الحالي.
- نجح تشغيل Electron وقاعدة البيانات وتسجيل الدخول، ونجح جسر تصدير كشف المورد PDF. أُصلح انتظار انتهاء عملية اختبار Electron قبل تنظيف ملفاته المؤقتة على Windows.
- فحص GitHub السابق `38797505477` كان ملغى أثناء `npm test`، وبقية فحوص Electron والواجهة متخطاة. لا يعد دليلاً على النجاح.
- أضيف فحص واجهة المخازن إلى Windows CI. بناء المثبت يبقى محصوراً بطلب تشغيل يدوي صريح مع `build=true`؛ لم يُنفذ أثناء هذه المراجعة.

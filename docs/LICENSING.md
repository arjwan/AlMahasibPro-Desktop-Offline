# جهاز رئيسي واحد وخمسة كاشيرات

النسخة المثبتة تتطلب ترخيص Ed25519 موقّعاً؛ تشغيل المصدر للتطوير مسموح على loopback فقط دون تفعيل. اتصال LAN يتطلب التفعيل حتى في وضع التطوير. يتضمن الترخيص هوية الجهاز الرئيسي، معرف العميل، معرف الرخصة، جهازاً رئيسياً واحداً وخمسة كاشيرات. نسخ ملف الترخيص إلى جهاز رئيسي آخر يرفض بسبب اختلاف هوية الجهاز. نسخ قاعدة البيانات لا ينقل التفعيل؛ ملف `license.token` منفصل بجوار القاعدة.

## إعداد المطور قبل أي مثبّت تجاري

أنشئ زوج مفاتيح مرة واحدة على جهاز المطور، واحفظ الخاص خارج المستودع وملفات العميل:

```powershell
openssl genpkey -algorithm ED25519 -out D:\DeveloperSecrets\alma-private.pem
openssl pkey -in D:\DeveloperSecrets\alma-private.pem -pubout -out license-public.pem
```

ضع محتوى المفتاح **العام فقط** في متغير مستودع GitHub `ALMAHASIB_LICENSE_PUBLIC_KEY` للبناء الآلي. لا تضع الخاص في GitHub أو المثبّت أو جهاز العميل. يمنع `beforePack` البناء عند غياب المفتاح العام أو عدم صحته. لم تُنشأ مفاتيح إنتاج في هذا التعديل.

بعد تثبيت النسخة، سجل الدخول محلياً من الجهاز الرئيسي؛ تعرض لوحة التفعيل معرف الجهاز. أصدر الترخيص من جهاز المطور:

```powershell
node tools/issue-license.mjs D:\DeveloperSecrets\alma-private.pem MACHINE_ID CUSTOMER_ID LICENSE_ID
```

ألصق الناتج في لوحة التفعيل محلياً بحساب المدير. الترخيص دائم ما لم يُحدد `expires` في الحمولة الموقعة. تغيير Windows/هوية الجهاز يتطلب مراجعة المطور وإصدار تفعيل جديد. احتفظ بسجل العملاء ومعرفات الرخص خارج أجهزة العملاء.

## LAN

شغل النسخة الرئيسية بمتغير `ALMAHASIB_HOST` يساوي عنوان IPv4 الخاص بالجهاز الرئيسي، ثم أتح المنفذ 3765 في جدار حماية Windows للشبكة الخاصة فقط. مثال مؤقت من PowerShell قبل تشغيل التطبيق:

```powershell
$env:ALMAHASIB_HOST='192.168.1.10'
```

يفتح الكاشير `http://192.168.1.10:3765` في متصفح ثابت؛ الأجهزة تستخدم قاعدة رئيسية واحدة ومعاملات SQLite، ولا تُنسخ القاعدة لتشغيل خمس قواعد منفصلة. تسجيل متصفح جديد يحجز كاشيراً؛ مسح الكوكيز يستلزم تحرير تسجيله القديم من الإعدادات. الجهاز الرئيسي يُميز من اتصال loopback ولا يستهلك مقعد كاشير. لا تستخدم reverse proxy يعرض العملاء كاتصالات loopback. ماسح Android يحتاج إعداد HTTPS وشهادة موثوقة على الهاتف؛ أُعيد استخدام البروتوكول الموجود.

## حدود الحماية واختبارات التسليم

التوقيع يمنع تعديل بيانات الترخيص أو استخدامه على هوية جهاز مختلفة في النسخة الأصلية. هوية Windows تعتمد MachineGuid؛ استنساخ النظام كاملاً أو تعديل المصدر لتجاوز التحقق خارج ضمان هذه الآلية. وجود المصدر لدى شخص يسمح له بإزالة فحوص الترخيص؛ لا يوجد منع مطلق لذلك. التفعيل دون إنترنت لا يوفر إلغاءً مركزياً فورياً أو كشفاً مركزياً لاستنساخ الأجهزة. لا تُعطَ مفاتيح المطور الخاصة لأي عميل.

اختُبر التوقيع، رفض جهاز آخر/توقيع معدل/صلاحية منتهية، التفعيل والحفظ ورفض التفعيل البعيد، ومنطق جهاز رئيسي وخمسة متصفحات كاشير ورفض السادس. اختبار ستة حواسيب Windows فعلية، تبدل الشبكة، إغلاق/إعادة تشغيل الرئيسي، واستمرار الكوكيز مطلوب قبل التسليم. التسجيل بالكوكيز لا يساوي ربطاً عتادياً لكل كاشير.

# المحاسب برو — Desktop Offline v0.3 (نسخة تطوير)

- SQLite محلية، مبيعات وحركات مخزون ضمن معاملات قاعدة البيانات.
- تعليق الفواتير وعرضها وإتمامها من القاعدة مع خصم المخزون عند الإتمام.
- باركود USB، إيصال عبر نافذة طباعة المتصفح، واختبارات API تكاملية.
- تشغيل محلي: `npm start` ثم `http://127.0.0.1:3765` (Node.js 22.13+).
- إعداد Electron لإنشاء مثبت EXE على Windows: راجع `BUILD-WINDOWS.md`.
- الأصناف والأرقام المعروضة تجريبية. لا توجد بعد منظومة محاسبية كاملة أو صلاحيات أو ترخيص 5 أجهزة أو LAN أو ماسح هاتف أو طباعة صامتة.
- لم يتم إنشاء أو اختبار EXE في بيئة Linux الحالية لعدم توفر حزم Electron وعدم الوصول إلى npm؛ تجهيز البناء ليس إثباتًا لنجاحه.
